# IT Market Intelligence Board

India + Global IT job-market intelligence and personal career planning.

## Stack
- Web: Next.js + TypeScript + Tailwind + shadcn/ui + ECharts
- API: FastAPI + Pydantic
- Data: Supabase PostgreSQL (Mumbai), object storage
- Workers: Redis + Celery
- Analytics: SQL + Python/Polars
- AI: provider-agnostic, evidence-grounded LLM layer
- Deploy: Vercel web; API/worker container; Supabase

## Initial markets
India, USA, UK, Germany, Canada, Singapore. Coverage depends on licensed source availability and must be shown with freshness metadata.

## Trust rules
1. Job advertisements are not official vacancies unless the source defines them that way.
2. Never combine incompatible sources without methodology disclosure.
3. Every chart shows source, period, geography, sample and freshness.
4. AI cannot invent numbers or citations; forecasts are clearly labeled.
5. Respect source terms, rate limits and licensing; no login/CAPTCHA bypass.
